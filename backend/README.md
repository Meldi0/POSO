# POSO Backend Architecture (Aiven for MySQL)

> **PEMBERITAHUAN MIGRASI RESMI**:
> Seluruh backend dan lapisan akses data POSO telah resmi dimigrasikan dari Google Apps Script / Google Sheets ke **Node.js / Express API** dengan database relasional **Aiven for MySQL** (SSL Mode: REQUIRED).
>
> Direktori aktif backend berada di folder:
> `server/`
>
> Script legacy Google Apps Script telah diarsipkan dan dinonaktifkan di `archive/legacy_gas/`.
